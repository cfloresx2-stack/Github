# ElectraNOM

Plataforma para diseño, cálculo, validación y documentación de instalaciones
eléctricas industriales conforme a la NOM-001-SEDE-2018. iPhone · iPad · Mac · Web.

- [`engine/`](engine/): motor de cálculo eléctrico determinístico en Rust (carga, demanda, conductores, caída de tensión). Ver [`engine/README.md`](engine/README.md).
